# blackbox criteria

## v3 contract surface

exports:
- `Hash` (type) — branded string
- `asHashSha256(message: string): Hash` — sync
- `asHashShake256(message: string, options?: { bytes: number }): Hash` — sync
- `isHashSha256(input: string): input is Hash` — type guard with `.assure()`

removed:
- `asHashMd5` — dropped (md5 is cryptographically broken)
- `asHashSha256Sync` — redundant (all functions are now sync)

---

# usecase.1 = produce a sha256 hash

```
given('a string message')
  when('asHashSha256 is called')
    then('it returns a 64-character lowercase hex string')
      sothat('the output is a valid sha256 digest')
    then('it returns a branded Hash type')
      sothat('callers get compile-time safety against raw strings')
    then('it is synchronous — no promise returned')
      sothat('callers can use it without await')

given('the same message twice')
  when('asHashSha256 is called both times')
    then('both calls return the same hash')
      sothat('the function is deterministic')

given('two different messages')
  when('asHashSha256 is called on each')
    then('the hashes differ')
      sothat('distinct inputs produce distinct fingerprints')

given('an empty string')
  when('asHashSha256 is called')
    then('it returns the known sha256 of empty string: e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855')
      sothat('the implementation matches the sha256 spec')

given('a unicode string with multi-byte characters')
  when('asHashSha256 is called')
    then('it returns a valid 64-character hex hash')
      sothat('utf-8 encode is handled correctly across all runtimes')

given('a known test vector: "hello world"')
  when('asHashSha256 is called')
    then('it returns b94d27b9934d3e08a52e52d7da7dabfac484efe37a5380ee9088f7ace2efcde9')
      sothat('the output matches the canonical sha256 for this input')
```

# usecase.2 = produce a shake256 hash

```
given('a string message with default options')
  when('asHashShake256 is called')
    then('it returns a 64-character lowercase hex string (32 bytes default)')
      sothat('the default output length matches 256 bits')
    then('it is synchronous — no promise returned')

given('a string message with custom byte length')
  when('asHashShake256 is called with { bytes: 16 }')
    then('it returns a 32-character hex string')
      sothat('output length = bytes * 2 hex chars')
  when('asHashShake256 is called with { bytes: 64 }')
    then('it returns a 128-character hex string')
      sothat('variable-length output works for extended digests')

given('the same message and same options twice')
  when('asHashShake256 is called both times')
    then('both calls return the same hash')
      sothat('the function is deterministic')

given('two different messages')
  when('asHashShake256 is called on each')
    then('the hashes differ')
```

# usecase.3 = validate a sha256 hash string

```
given('a valid 64-character hex string produced by asHashSha256')
  when('isHashSha256 is called')
    then('it returns true')
      sothat('valid hashes pass the type guard')

given('a string that is not a valid sha256 hash')
  when('isHashSha256 is called')
    then('it returns false')

given('a string that is not a valid sha256 hash')
  when('isHashSha256.assure is called')
    then('it throws an error with message "assure.rejection: input does not satisfy type.check"')
      sothat('callers can fail fast on invalid hash formats')
```

# usecase.5 = removed exports

```
given('a codebase that previously imported asHashMd5')
  when('it upgrades to v3')
    then('the import fails at compile time — asHashMd5 does not exist')
      sothat('callers are forced to migrate to sha256 or shake256')

given('a codebase that previously imported asHashSha256Sync')
  when('it upgrades to v3')
    then('the import fails at compile time — asHashSha256Sync does not exist')
      sothat('callers migrate to asHashSha256 which is now sync')
```
